# Library — Simple Book Collection UI

A small browser-based library app for managing a collection of books. This project provides a lightweight front-end script that stores books in-memory, renders them as cards, and supports marking books as "read" and removing them.


## Features

- Add books (title, author, published date).
- Render books as card elements in the page.
- Toggle "read" state on a book.
- Remove books from the collection.
- Works entirely in the browser (in-memory storage).

## Quickstart

1. Open `index.html` in a browser (no build step required).
2. The app expects the following elements to exist in the page:
   - A container element with class `books` where book cards will be rendered.
   - A dialog element with id `newBook` containing inputs for adding a new book.
   - Inputs with ids `title`, `author`, and `date` for the add form.
   - A button with id `addBook` that submits the form to add a book.


Open the page in a modern browser (the script uses crypto.randomUUID(), so a current browser is recommended).


## Implementation notes (script.js)

The code's primary pieces:

- myLibrary
  - An array used as in-memory storage for Book objects. New books are unshifted (added to the front).

- Book(name, author, datePublished)
  - Constructor function creating a book object with these properties:
    - id — generated by crypto.randomUUID()
    - name — title string
    - author — author string
    - published — date string
    - read — boolean (default false)

- addToLibrary(name, author, datePublished)
  - Creates a Book and inserts it at the start of myLibrary.
  - Example: addToLibrary("Black Swan", "Nassim Taleb", "2003")

- displayBooks()
  - Renders the contents of myLibrary into the `.books` container.
  - For each book it creates a `.card` element with the following inner HTML:
    - <p> Book Title :  ${book.name} </p>
    - <p> Book Author :  ${book.author} </p>
    - <p> Date Published :  ${book.published} </p>
    - <button class="read-book false-read" data-id="..." data-read="..."> Read </button>
    - <button class="remove-book" data-id="..."> Remove </button>

  - Event behavior bound per-card:
    - Read button: toggles the `read` flag on the book object and swaps the read button's class between `false-read` and `true-read`.
    - Remove button: removes the book from myLibrary (splice) and re-renders.
